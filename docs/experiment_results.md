## 雙刺激與延遲 T-maze

每個資料集運行 45 組：3 個 seed × 3 種拓樸 ×（雙刺激的可塑／凍結，以及 T-maze 的可塑／凍結／每步重設記憶）。可塑組更新既有 motor incoming edges；凍結組權重 L1 改變量均為 0。測試凍結權重並使用 agent 副本，保持訓練 RNG 與神經狀態不被評估改動。

下表是三個 seed 的**訓練後成功率平均值**。合成網路每组訓練 1,200 回合、評估 200 回合；真實幼蟲子圖每组訓練 600 回合、評估 100 回合。兩個資料集預算不同，不能視為嚴格的資料集優劣比較。

| 資料／任務 | 原圖可塑 | 原圖凍結 | 保持度數重接，可塑 | G(n,m) 隨機圖，可塑 | 原圖每步重設記憶 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 合成 68 節點，雙刺激 | 88.17% | 47.83% | 86.67% | 61.83% | — |
| 合成 68 節點，T-maze | 65.17% | 54.67% | 71.83% | 56.50% | 52.00% |
| 幼蟲 192 節點，雙刺激 | 48.67% | 46.67% | 47.33% | 47.67% | — |
| 幼蟲 192 節點，T-maze | 51.33% | 50.00% | 51.00% | 51.00% | 50.67% |

合成原圖雙刺激由 47.83% 提升到 88.17%，支持這個工程介面與局部更新規則可以完成簡單學習。合成原圖 T-maze 提升較小；保持度數的重接图反而比原圖成功率高，沒有證據支持原始拓樸一定較好。合成網路本來就是程式產生的測試網路，不能稱為生物拓樸優勢。

真實幼蟲子圖兩個任務都接近二選一的 50% 基準。原圖雖有非零權重變化（雙刺激平均 L1 = 3.31、T-maze = 1.50），這些結果不能支持可靠學習成功。此子圖缺少 motor 註記，輸出是工程指定；NT 全為 unknown，模型亦有明確假設。只有三個 seeds，未做統計顯著性檢定；詳細 seed 差異及描述統計見 JSON。

T-maze 消融每個動作前同時清除神經動態和活動 trace，不能分離 recurrent topology 與人工加入的短期 trace 各自的貢獻。結果中的記憶效應不能單獨解釋為生物工作記憶湧現。

## 2×2 與 3×3 魔方課程

兩組均使用 seed 0，依序訓練打亂深度 1、2、3，每階段 300 回合，評估 100 回合。2×2 用合成 68 節點網路；3×3 用 FlyWire v783 的 512 節點、3,764 邊子圖。**這些是 MaleCNS 加入前執行的課程結果，不能改標為 MaleCNS 的成績。**

| 組別 | 深度 1 訓練起始狀態：前 → 後 | 深度 2：前 → 後 | 深度 3：前 → 後 | 最終保留起始狀態：前 → 後 | 隨機動作基準 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 2×2／合成 | 16% → 23% | 6% → 7% | 4% → 4% | 4% → 1% | 1% |
| 3×3／FlyWire | 8% → 8% | 1% → 1% | 0% → 0% | 0% → 0% | 0% |

前三欄評估訓練使用過的起始狀態，只反映對這些狀態的表現，不是泛化測試。最後一欄保留評估使用 16 個起始狀態，均從所有訓練階段的起始池移除。仍有一部分在訓練的轉動軌跡中被拜訪，因此另做更嚴格的審計：

| 組別 | 訓練互動次數 | 保留起始狀態數 | 訓練軌跡曾拜訪 | 完全未拜訪狀態數 | 完全未拜訪狀態評估成功率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 2×2／合成 | 5,122 | 16 | 8 | 8 | 1% |
| 3×3／FlyWire | 5,338 | 16 | 6 | 10 | 0% |

目前 2×2 的最終保留測試未優於均勻隨機動作，3×3 在本次預算內沒有解出保留測試。課程確實改變權重（總 L1 分別為 21.14、0.28），但沒有證明已學會通用解法。100 次評估會重複少量起始狀態，並不等於 100 個獨立新狀態；旋轉對稱等價狀態尚未跨集合隔離。打亂深度也不是最短解距離。

限時續訓功能是另一個互動協定：反覆挑戰同一狀態，首次解出就停止，嘗試失敗給 −0.1，保留權重至下一輪。上表課程使用 solved reward、固定回合預算及分離狀態評估。不能把限時模式的某次「解出」視為表格中的泛化成績。

## 完整成年資料與可視化

MaleCNS 已匯入 166,700 個分類神經元、25,582,837 個有向節點對；互動預設使用其 512 節點、9,079 邊子圖。畫面解剖背景有 140,638 個真實位置點，26,062 個沒有來源座標的節點不捏造位置。另含 12 個真實 SWC 骨架樣本。來源、篩選與授權見 [MaleCNS 說明](malecns.md)。

兩份完整成年圖均執行了 30 ms 的 LIF 基本運行檢查：

| 圖 | 模擬節點 | 有向邊 | 本機耗時 | 曾放電節點 |
| --- | ---: | ---: | ---: | ---: |
| FlyWire v783 | 139,255 | 2,700,513 | 約 1.31 秒 | 26 |
| MaleCNS v1.0 | 166,700 | 25,582,837 | 約 6 秒 | 31 |

這是完整圖可載入、稀疏計算可運行且數值有限的檢查，時間只描述這台電腦及當次刺激設定。多數節點在短時間内安靜，不能據此證明全腦動態或生理功能已重現，也不是全腦魔方訓練。原始 metrics 保存在結果目錄。

完整 MaleCNS 另經過 `train-timed --seconds 5 --size 3 --depth 1` 的流程檢查：完成 1 次模型決策並保存完整 checkpoint，停止原因為時間到，連同壓縮存檔共約 54.6 秒。沒有完成整次嘗試、沒有成功或權重更新，故此檢查只支持完整模型的執行與保存能力。原始摘要見 [`malecns_timed_smoke.json`](../results/2026-09-13/malecns_timed_smoke.json)。

互動子圖的瀏覽器驗證則使用 MaleCNS 的 512 節點：2 秒上限完成 1,410 次決策後停止並保存，本輪權重 L1 變化為 0.02294；下一輪接續，手動停止後累積 1,619 次決策。重新開啟 checkpoint 回放仍保留 60 幀，沒有被上一轮的最後即時狀態取代。1600 px 桌面和 390 px 手機寬度均無 JavaScript 錯誤或橫向溢出。這些是功能檢查，不是學習效果評估。

## 重現指令

在專案根目錄安裝 `python -m pip install -e .` 後執行。Windows 也可將 `python -m connectome_lab` 換成 `.\scripts\run.cmd`。

```bash
python -m connectome_lab benchmark --graph synthetic --episodes 1200 --eval-episodes 200 --seeds 0 1 2 --output outputs/synthetic_benchmark
python -m connectome_lab benchmark --graph larval --episodes 600 --eval-episodes 100 --seeds 0 1 2 --output outputs/larval_benchmark
python -m connectome_lab curriculum --graph synthetic --size 2 --depths 1 2 3 --episodes 300 --eval-episodes 100 --seed 0 --output outputs/cube2_curriculum
python -m connectome_lab curriculum --graph flywire --size 3 --depths 1 2 3 --episodes 300 --eval-episodes 100 --seed 0 --output outputs/cube3_curriculum
```

benchmark 可能需要數十分鐘，耗時取決於 CPU。`report.html` 用瀏覽器直接開啟；`results.json` 含完整結構化結果，`episodes.csv` 記錄訓練回合。各子實驗的模型另存 `agent.npz`。執行記錄保留 Python、NumPy、平台及圖指紋；不同數值運算環境可能產生浮點差異，不要求重新執行後的耗時或整份 JSON 雜湊相同。

驗證程式：

```bash
python -m pip install -e ".[malecns]"
python -m unittest discover -s tests -v
node --test tests/test_dashboard_js.mjs
```

Python 測試涵蓋圖匯入、實際資料、LIF、局部規則、環境、評估隔離、魔方狀態分離、checkpoint 接續及本機 HTTP API；Node 測試檢查魔方轉動幾何與神經顯示換算。測試使用已附資料與小型原始格式 fixture，不會下載完整原始資料。GitHub Actions 也執行這兩組檢查。一般互動操作不需要 Node。

交付前本機結果：93 項 Python 測試、6 項 Node 測試全部通過；Windows `scripts/run.cmd --help` 啟動器與上述瀏覽器流程也已實際執行。
