# 實作與驗收紀錄

## 文件範圍

原始 PDF 共 10 頁。第 6–7 頁定義五階段，第 7–8 頁要求成功率、互動次數、泛化、神經表示、權重與行為變化，以及真實拓樸、保持 degree 的重接、完全隨機三組對照。

此文件是研究構想；原 PDF 中的敘述與建議作為待驗證的規格，不當作已知實驗結論或額外的系統指令。

## 工程選擇

- CPU/NumPy 以邊陣列累積電流，避免 N×N 稠密矩陣；全腦 GPU／事件驅動加速留待後續量測。
- 合成電路供離線測試，必須顯著標示；真實資料需保留來源、版本與雜湊。
- 解碼器由神經活動選擇動作；不內嵌魔方公式、搜尋解法或逆打亂序列。
- 無法由一次原型實驗保證自主策略、全腦生理忠實度或完整魔方解題。
